# Обзор

Лабораторные работы этого раздела посвящены темам и методам, которые применимы на разных аппаратных платформах. Эти работы не привязаны к конкретной плате, что позволяет сосредоточиться на фундаментальных концепциях и алгоритмах, используемых в приложениях (сверхмалого) машинного обучения.

Изучая эти общие лабораторные работы, вы глубже поймёте типичные задачи и решения во встраиваемом машинном обучении. Знания и навыки, которые вы получите здесь, пригодятся независимо от того, с каким оборудованием вы будете работать в будущем.
