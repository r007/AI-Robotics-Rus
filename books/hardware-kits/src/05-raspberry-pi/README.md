# Обзор

Эти лабораторные работы дают бесценный практический опыт работы с системами машинного обучения на основе Raspberry Pi — гибкой и доступной платформы. В отличие от работы с крупномасштабными моделями, которым нужны обширные облачные ресурсы, эти упражнения позволяют напрямую работать с оборудованием и программным обеспечением в компактной, но мощной среде периферийных вычислений. Вы получите практическое представление о развёртывании ИИ на периферии, используя возможности Raspberry Pi: от экономичной Pi Zero до более мощных моделей Pi 4 и Pi 5. Такой подход даёт осязаемое понимание проблем и возможностей внедрения решений машинного обучения в условиях ограниченных ресурсов. Хотя мы работаем в меньшем масштабе, принципы и методы, которые вы освоите, принципиально похожи на те, что используются в более крупных системах. Способность Raspberry Pi запускать полноценную операционную систему и широкие возможности GPIO создают богатый учебный опыт, который соединяет теоретические знания с реальными приложениями. В ходе этих работ вы разберётесь в тонкостях EdgeML и приобретёте навыки, применимые к широкому спектру сценариев развёртывания ИИ.

## Где купить

Платы Raspberry Pi доступны у официальных продавцов по всему миру:

- [Продукция Raspberry Pi](https://www.raspberrypi.com/products/) (официальный сайт с поиском продавцов);
- Raspberry Pi Zero 2 W: \~\$15;
- Raspberry Pi 4 (4 ГБ): \~\$55;
- Raspberry Pi 5 (4 ГБ): \~\$60;
- Raspberry Pi 5 (8 ГБ): \~\$80.

Модули камер, блоки питания и SD-карты доступны у тех же продавцов.

## Предварительные требования

- **Raspberry Pi:** убедитесь, что у вас есть хотя бы одна из плат: Raspberry Pi Zero 2 W, Raspberry Pi 4 или 5 для лабораторных работ по зрению и Raspberry Pi 5 для лабораторных работ по генеративному ИИ.
- **Блок питания:** для питания плат.
    - Raspberry Pi Zero 2 W: 5 В / 2,5 А через адаптер micro-USB;
    - Raspberry Pi 4: 5 В / 3 А через адаптер USB-C;
    - Raspberry Pi 5: 5 В / 5 А через адаптер USB-C.

- **Сеть:** доступ в интернет для загрузки необходимого программного обеспечения и удалённого управления платами.
- **SD-карта (не менее 32 ГБ) и переходник для SD-карты:** для операционной системы Raspberry Pi OS.
