# Агентные системы машинного обучения

Этот том учебника «Machine Learning Systems» рассказывает о системах, в которых основная модель работает в цикле вместе с контекстом, памятью, инструментами и средой выполнения. Единица инженерной работы здесь — не отдельный запрос к модели, а **траектория**: вся история делегированной задачи от цели до проверенного результата.

> [!NOTE]
> Книга в работе. Переведены главы, перечисленные в оглавлении. Остальные главы пока доступны только в оригинале.

Оригинал: [mlsysbook.ai](https://mlsysbook.ai). Авторство, лицензия и список изменений относительно оригинала — на страницах «Авторство и лицензия» и «Происхождение материалов» в конце книги.
