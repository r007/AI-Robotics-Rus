# 7. Визуальное восприятие

Камера позволяет находить объекты и понимать сцену. Результаты обработки изображений используются, чтобы направлять захват, отслеживание, укладку и сборку.

## 7.1 Двумерное восприятие

Изображение задаёт пиксельную систему координат с началом в левом верхнем углу (рис. 10). По модели точечной камеры (pinhole) координаты пикселя $(u, v)$ связаны с координатами точки $(X, Y, Z)$ в системе камеры:

$$u = f\frac{X}{Z}, \qquad v = f\frac{Y}{Z}$$

где $f$ — фокусное расстояние. По одному изображению глубина $Z$ неизвестна, поэтому расстояние до объекта и позу камеры определяют с помощью калибровочных маркеров, например ArUco (рис. 11). Подробности о внутренних параметрах камеры автор отсылает к внешней статье.

## 7.2 Трёхмерное восприятие

Трёхмерные датчики измеряют глубину напрямую, поэтому сцена восстанавливается точнее. Результат — облако точек, то есть набор точек $\{(x_i, y_i, z_i)\}_{i=1}^{N}$ (рис. 12).

Типичный сценарий: получить облако точек объекта и зарегистрировать его относительно идеального облака из CAD-модели (рис. 13). Так находят позу объекта в системе координат камеры. Облака точек удобно обрабатывать в Open3D. Для визуальной проверки автор рекомендует MeshLab (рис. 14).
