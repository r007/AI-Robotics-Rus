# Обозначения

| Символ | Значение |
|---|---|
| $n$ | число степеней свободы робота |
| $m$ | число минимальных инерционных параметров |
| $q \in \mathbb{R}^{n\times 1}$ | вектор положений суставов |
| $\dot q \in \mathbb{R}^{n\times 1}$ | вектор скоростей суставов |
| $\ddot q \in \mathbb{R}^{n\times 1}$ | вектор ускорений суставов |
| $\tau \in \mathbb{R}^{n\times 1}$ | вектор моментов в суставах |
| $\mathcal F \in \mathbb{R}^{6\times 1}$ | обобщённая сила и момент, которые робот прикладывает к собственному концу |
| $\mathcal F_{ext} \in \mathbb{R}^{6\times 1}$ | обобщённая сила и момент, которые внешняя среда прикладывает к концу робота |
| $X = [x, y, z, \alpha, \beta, \gamma] \in \mathbb{R}^{6\times 1}$ | поза в рабочем (декартовом) пространстве |
| $J(q) \in \mathbb{R}^{6\times n}$ | матрица Якоби |
| $R \in \mathbb{R}^{3\times 3}$ | матрица поворота |
| $T \in \mathbb{R}^{4\times 4}$ | однородная матрица преобразования |
| $Tr: q \mapsto X$ | прямая кинематика |
| $M(q) \in \mathbb{R}^{n\times n}$ | обобщённая матрица масс |
| $C(q, \dot q) \in \mathbb{R}^{n\times n}$ | матрица кориолисовых сил и трения |
| $G(q) \in \mathbb{R}^{n\times 1}$ | вектор гравитационных моментов |
| $A(q, \dot q, \ddot q) \in \mathbb{R}^{n\times m}$ | регрессорная матрица для минимального набора инерционных параметров |
| $\Theta \in \mathbb{R}^{m\times 1}$ | минимальный набор инерционных параметров |
| $t \in \mathbb{R}_+$ | непрерывное время |
| $t_k \in \mathbb{R}_+$ | дискретный момент времени |
| $P(t) \in \mathbb{R}^{6\times 1}$ | заданная траектория позы в рабочем пространстве |
