# 2. Конструкция

Проектирование многосуставного робота начинается с двух вопросов: сколько у него степеней свободы и где, в каком направлении вращается каждый сустав. В качестве примера взят UR5 компании Universal Robots. У него шесть подвижных суставов, поэтому конец робота может двигаться с шестью степенями свободы в рабочем пространстве (рис. 1).

Чтобы проверить конструкцию, сборочный файл CAD переводят в формат URDF (с помощью инструмента sw2urdf), а затем проверяют модель в симуляторе PyBullet.
