# Введение в робототехнику

Это русскоязычный конспект учебного материала **«机器人学简介»** («Краткое введение в робототехнику»). Автор оригинала — 东林钟声, Ухань, ноябрь 2022, 23 страницы. Исходный PDF лежит в репозитории Embodied-AI-Guide в папке `files/`.

## Что внутри

- [Обозначения](00-notation.md) — перевод таблицы символов из оригинала.
- Главы 1–7 — пересказ каждого раздела на русском языке с ключевыми формулами. Нумерация совпадает с оригиналом.
- [Рисунки и таблицы](figures.md) — переведённые подписи и надписи внутри рисунков.

## Чего здесь нет

Это не построчный перевод оригинального текста. Полный перевод требует согласия автора либо подтверждённой открытой лицензии на материал. В тексте PDF лицензия не указана.
