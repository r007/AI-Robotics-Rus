# Примеры: быстрое знакомство с Every-Embodied

Эта папка содержит примеры для быстрого знакомства с проектом для новичков. Цель — **низкий порог входа, работа на разных платформах и интерактивность**.

## 1. Рекомендуемый пример

### `01_hello_every_embodied_mujoco.py`

Интерактивная демонстрация в MuJoCo в стиле презентации проекта. Она включает:

- после запуска выводит `Hello Every-Embodied`;
- по вводу `1/2/3/4` запускает разные действия:
  - `1`: манипулятор машет рукой (Wave);
  - `2`: забавное движение (Dance);
  - `3`: захват и укладка случайного кубика (Random Pick-and-Place);
  - `4`: режим автоматического повтора (удобно для записи экрана);
- использует планирование траектории и обратную кинематику (IK):
  - по возможности `ruckig` (траектория с ограничением рывка, jerk);
  - если он не установлен, автоматически переключается на интерполяцию quintic;
- повышенная стабильность захвата:
  - ограничения на ориентацию конечного эффектора (при захвате сохраняется более естественное положение);
  - проверка достижимости случайных точек и простая фильтрация столкновений (сначала отбор, потом захват);
  - защита от подбрасывания предмета при укладке: стадия стабилизации после касания стола, а также сначала раскрытие захвата, потом подъём и отход;
- не требует больших языковых моделей и GraspNet, подходит для обучения и быстрой демонстрации;
- оформление окна MuJoCo:
  - заголовок окна: `hello_every_embodied`;
  - в сцене включены подписи site, видна метка `hello_every_embodied`.

## 2. Запуск

Выполните из корня проекта:

```bash
# Обязательная зависимость
pip install mujoco

# Необязательно (рекомендуется): более плавное и инженерное планирование траекторий
pip install ruckig

python examples/01_hello_every_embodied_mujoco.py
```

Если графический интерфейс не запускается (например, удалённая машина без дисплея), используйте:

```bash
python examples/01_hello_every_embodied_mujoco.py --headless
```

Ускоренный запуск (отключается реальное время, `sleep`):

```bash
python examples/01_hello_every_embodied_mujoco.py --fast
```

Автоматический повтор (для записи видео):

```bash
python examples/01_hello_every_embodied_mujoco.py --autoplay --autoplay-rounds 3
```

## 3. Почему сначала MuJoCo?

Для сценария «быстрое знакомство и кроссплатформенность» у MuJoCo есть преимущества:

- лёгкая установка: достаточно `pip install mujoco`;
- кроссплатформенность: работает в Windows, Linux и macOS;
- стабильная физическая симуляция, подходит для демонстрации планирования траекторий и управления.

Для более сложных задач (визуальное восприятие, параллельное обучение, большие сцены) можно перейти к Isaac Sim, ManiSkill, Habitat и другим средам.
