# Глоссарий

Термины даны так, как они использованы в книге. Английские названия сохранены там, где они устоялись в литературе или совпадают с именами в коде.

| English | Русский | Комментарий |
|---|---|---|
| embodied AI | воплощённый ИИ | ИИ, связанный с физическим телом и средой |
| embodiment | воплощение | тип робота; в коде — `EmbodimentTag` |
| policy | политика (стратегия) | отображение наблюдения в действие |
| rollout | rollout | прогон эпизода политики в среде |
| action chunk | блок действий | несколько будущих действий, предсказанных за один вызов |
| action head | головка действий | выходной модуль модели для действий |
| modality | модальность | тип входных данных: видео, состояние, действие, язык |
| affordance | аффорданс | возможность взаимодействия, которую предоставляет объект |
| fine-tuning | дообучение | настройка предобученной модели на новых данных |
| post-training | постобучение | дообучение на данных конкретного воплощения |
| sim-to-real | перенос из симуляции в реальность | переход от симуляции к реальному роботу |
| DAgger | DAgger | итеративное имитационное обучение с экспертом |
| OOD (out-of-distribution) | OOD (вне распределения) | ситуации, которых не было в обучающих данных |
| checkpoint | checkpoint | сохранённое состояние модели в процессе обучения |
| VLA (Vision-Language-Action) | VLA | модель «зрение — язык — действие» |
| VLM (Vision-Language Model) | VLM | визуально-языковая модель |
| DiT (Diffusion Transformer) | DiT | диффузионный трансформер |
| physical_success | physical_success | поле результата: физический успех задачи |
| legacy_success | legacy_success | поле результата по прежнему критерию успеха |
| eef_abs / eef_delta | eef_abs / eef_delta | абсолютное и относительное управление схватом |
| MuJoCo | MuJoCo | физический движок для симуляции |
| ONNX | ONNX | открытый формат обмена моделями |
| HBM / BPU | HBM / BPU | файл модели и блок вывода RDK X5 |
