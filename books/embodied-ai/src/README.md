# Воплощённый ИИ и робототехника

Учебник по воплощённому искусственному интеллекту: от кинематики и координации «рука — глаз» до моделей VLA, навигации, симуляции, развёртывания на бортовых платах и проектов для самостоятельной работы.

Это русский перевод материала [every-embodied](https://github.com/datawhalechina/every-embodied) проекта Datawhale и соавторов. Исходный материал распространяется по лицензии CC BY 4.0. Перевод выполнил Сергей Монин.

## Как читать

- Главы идут по порядку, но каждую можно читать отдельно: внутренние ссылки ведут на соответствующие разделы.
- Термины собраны в [глоссарии](glossary.md).
- Примеры кода можно запускать. Комментарии и строки интерфейса переведены. Ключевые слова, по которым программа разбирает китайский ввод, оставлены на китайском языке и сопровождаются переводом.

## Что не вошло в книгу

- Версии в формате PDF и DOCX, а также крупные файлы весов моделей.
- Сохранённые копии сайтов производителей. Вместо них даны ссылки на официальные адреса.
- Внутренние ссылки, которые открываются только по приглашению, и рекламные блоки исходного текста.

## Статус перевода

Текст, примеры кода, подписи в таблицах и диаграммах, а также имена файлов переведены. Растровые иллюстрации с китайскими надписями, в первую очередь схемы главы 01, пока не перерисованы.

## Ошибки и предложения

Замечания по тексту, коду и переводу принимаются через issue или pull request в репозитории проекта. Порядок работы описан в файле CONTRIBUTING.md репозитория.
