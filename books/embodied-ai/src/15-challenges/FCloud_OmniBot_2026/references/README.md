# Внешние проекты и границы лицензий

| Проект | Публичное назначение | Что нельзя заменить им |
| --- | --- | --- |
| SIMPLE | генерация данных для G1 всем телом и справка по конечному автомату | официальная сцена FCloud и итоговый результат |
| Официальный Isaac Lab от Unitree | интерфейсы G1, Dex1, камер, DDS (система распространения данных) и сбор через Quest | домашняя сцена FCloud |
| CAPX/B1K | разбиение домашних задач, подъезд к столу и справка по управлению наблюдением | робот и интерфейс задачи FCloud |
| Пример захвата фруктов в MuJoCo | временная структура захвата KUKA + двухпалый захват и реальный контакт | среда Isaac Sim соревнования |
| AnyGrasp | генерация кандидатов захвата по облаку точек | сегментация цели, калибровка координат, IK (обратная кинематика) и планирование столкновений |
| SAM3 | сегментация изображений и выделение целевой области | оценка глубины, контакт захвата и подтверждение укладки |
| cuRobo | IK, проверка столкновений и оптимизация траекторий | распознавание предметов, контакт захвата и конечный автомат задачи |

При повторном использовании внешнего кода сохраняйте ссылку на вышестоящий репозиторий, зафиксированную версию и исходную лицензию. Этот документ не распространяет веса сторонних моделей, ассеты роботов и ограниченные наборы данных.
