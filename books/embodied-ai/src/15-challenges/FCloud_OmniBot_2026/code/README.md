# Пояснение к лёгкому коду

Код в этом каталоге — публичный снимок проекта соревнования; он нужен прежде всего для понимания интерфейсов, записи данных и офлайн-самооценки. Это не готовое окружение с Isaac Sim (симулятор роботов), Isaac Lab (фреймворк для обучения роботов) и официальными ассетами, которое запускается одной командой.

## Границы кода

- `omnibot_agent/`: лёгкие модули, связанные с наблюдениями, планированием, адаптацией действий, журналированием и локальной самооценкой.
- `configs/`: шаблоны конфигураций, относящиеся к публичному интерфейсу; локальные пути и токены удалены.
- При реальном запуске замените `$PROJECT_ROOT` (корень проекта), `$DATA_ROOT` (корень данных) и `$MODEL_ROOT` (корень моделей) на собственные пути.

## Рекомендуемый порядок

1. Сначала запустите самопроверку на чистом Python (язык программирования) и оценку JSON (формат структурированных данных).
2. Затем на машине с уже установленным официальным симуляционным окружением проверьте интерфейс камеры и действий на одном эпизоде.
3. И только после этого подключайте реальную политику, обучение и полную оценку.

Выводы скриптов с пометками `oracle` (учитель с истинными значениями), `bootstrap` (проверка запуска) или `smoke` (дымовой тест) годятся только для проверки цепочки. Если нет видео реального контакта, их нельзя использовать как официальные данные об успехе.
