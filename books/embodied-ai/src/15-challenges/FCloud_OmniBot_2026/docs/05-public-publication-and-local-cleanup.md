# Публичная публикация и очистка локальных файлов

## Разделение публикации

| Место | Содержимое | Что явно исключается |
| --- | --- | --- |
| GitHub `15-challenges/FCloud_OmniBot_2026/` | учебные материалы на русском языке, лёгкий код, шаблоны конфигураций, границы результатов и ссылки | веса, кеши, приватные журналы, токены, закрытые адреса |
| Hugging Face (платформа для моделей и данных) `Datawhale/fcloud-omnibot-2026-reproducibility` | снимки исходного кода, манифесты, обезличенные записи экспериментов, репрезентативные видео | пароли, закрытые ключи, неразрешённые ассеты, полное окружение |
| Локальная рабочая область | только `WORKSPACE_MEMORY.md` (рабочая память) | исходные журналы, кеши, окружения, загруженные архивы и промежуточные видео |

## Загрузка архива

```bash
git clone https://github.com/datawhalechina/every-embodied.git

# Архив набора данных на Hugging Face
git clone https://huggingface.co/datasets/Datawhale/fcloud-omnibot-2026-reproducibility
```

Файл `MANIFEST.sha256` (контрольные суммы файлов) в репозитории Hugging Face используется для сверки загруженных файлов. Видео и журналы — только доказательства, и они не превращаются в результат соревнования автоматически.

## Проверка перед публикацией

```bash
rg -n -i \
  'hf_[A-Za-z0-9]{20,}|sk-[A-Za-z0-9_-]{20,}|password|secret|private[_-]?key|api[_-]?key|/home/ubuntu|/data/Data' \
  15-challenges/FCloud_OmniBot_2026
```

Требования к результату: токенов, паролей и закрытых ключей быть не должно; абсолютные пути машины нужно заменить на `$PROJECT_ROOT` (корень проекта), `$DATA_ROOT` (корень данных) или примерные пути; из журналов удаляются приватные адреса и ссылки с аутентификацией; сторонний код сохраняет ссылки на вышестоящий проект, версию и лицензию.

## Принципы очистки

Локальный исходный каталог проекта можно удалять только после того, как успешно выполнены загрузка на GitHub, доступность файлов на Hugging Face, создание файла контрольных сумм и воспроизведение представительных видео. Очистка не распространяется на общий справочный каталог данных на 14 ТБ, на кеши моделей или на окружения, которые используют и другие проекты.
