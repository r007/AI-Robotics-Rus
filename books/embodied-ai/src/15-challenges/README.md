В публичном каталоге хранится только то, что можно безопасно распространять повторно. Исходные ассеты роботов, обучающие данные, веса моделей, приватные логи, токены доступа и учётные данные серверов в Git напрямую не кладутся. Если есть разрешение на повторное распространение, их нужно публиковать в соответствующем репозитории Hugging Face, а в README проекта фиксировать версию и SHA256.
