```text
[ ] Аккаунт разблокирован по порядку T1 -> T2 -> T3 -> T4
[ ] токен читается только из файла или переменной окружения и не записывается в историю команд и журналы
[ ] веса, dataset_stats.pkl, дерево кода и конфигурация развёртывания проверены по SHA
[ ] checkpoint и статистики лежат в согласованном каталоге, имена файлов совпадают с config
[ ] корень кода — минимальный образ external/robotwin_local
[ ] в пакете кода нет символических ссылок, жёстких ссылок, wandb, кешей, данных и резервных каталогов
[ ] импорт ACT проверен только на зависимостях, которые уже есть в официальном онлайн-окружении
[ ] результаты fixed fresh3/fresh10/fresh20 сохранены и не выбраны выборочно
[ ] сохранены ответ сервера, ID очереди, SHA на сервере и время
[ ] до дедлайна получена явная квитанция; один факт работы процесса загрузки не означает попадания в очередь
[ ] защищённый кандидат не перезаписан
```

## 2. Перед открытой публикацией в Git / Hugging Face

```text
[ ] `git status` подтверждает, что в коммит не попали чужие изменения пользователя
[ ] в репозитории нет токенов, приватных ключей, cookie, внутренних URL серверов
[ ] нет личных абсолютных путей, PID/PGID, портов и необработанных журналов
[ ] нет HDF5, checkpoint, pickle, safetensors, видео и больших кешей
[ ] нет проприетарных мешей Tron2, URDF/MJCF и сторонних ассетов без подтверждённой лицензии
[ ] в таблицах результатов указаны границы: local / diagnostic / official-online
[ ] все SHA относятся к файлам, которые доступны публично; иначе указываем их только как ссылку на приватный архив
[ ] README объясняет, какие официальные ассеты и лицензии нужны для воспроизведения
[ ] ресурсы Hugging Face публикуются в отдельных репозиториях моделей или наборов данных, их можно восстановить и проверить
[ ] сначала запустить сканирование и проверку ссылок в чистой копии репозитория
```

## 3. Что входит в публикацию

В этой публикации есть только:

- обезличенная сводка конфигурации обучения;
- скрипты аудита данных и инструменты манифеста публичных материалов;
- результаты экспериментов и разбор сбоев;
- итоговый онлайн-результат (25.3/100);
- опыт переноса ресурсов, топологии оценки, пакета отправки и обезличивания.

Здесь нет секретных материалов, которые позволили бы восстановить доступ к аккаунту или напрямую запустить проприетарный симулятор.

Если позже будут загружаться крупные файлы, сначала в README на Hugging Face укажите: лицензию источника, версии данных и моделей, число файлов, общий размер, SHA256, команду восстановления и известные ограничения.
