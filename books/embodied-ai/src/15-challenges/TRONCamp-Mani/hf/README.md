# Рекомендации по публикации на Hugging Face

Этот каталог описывает порядок публикации и не содержит весов модели, исходных траекторий, видео, токенов доступа или приватных журналов запусков.

## Рекомендуемое разделение

Если позже публиковать материалы на Hugging Face, разумно разделить их на два репозитория:

1. **Репозиторий кода**: конфигурации, скрипты аудита, протокол оценки и текст разбора из каталога `15-challenges/TRONCamp-Mani`.
2. **Репозиторий данных или моделей**: только обезличенные manifest, веса или публичные образцы, и только после подтверждения правил соревнования, лицензий данных и лицензий сторонних ассетов.

Не загружайте в публичные репозитории исходные данные соревнования, полные HDF5, checkpoint, учётные данные сервиса оценки, адреса машин, SSH-ключи или внутренние журналы. Крупные файлы загружайте через Git LFS или сегментированную загрузку Hugging Face и в README репозитория указывайте SHA256, версию, лицензию и способ восстановления.

## Проверка перед публикацией

Выполняйте локально, а токен передавайте через переменную окружения или интерактивный вход, не записывая его в скрипты:

```bash
cd 15-challenges/TRONCamp-Mani
bash code/scan_public_release.sh .
python3 code/build_public_manifest.py . --output /tmp/troncamp-manifest.json
```

После публикации сохраняйте созданный открытый manifest и SHA коммита в описании версии, чтобы читатели могли проверить, не изменились ли файлы.

Текущий репозиторий уже содержит воспроизводимый разбор проекта и строгий скрипт аудита обработанных данных, но он не заменяет проверку лицензий данных и не является официальным подтверждением результата соревнования.
