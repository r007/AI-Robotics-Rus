# Классификация сбоев

| Категория | Доказательства | Влияние | Дальнейшее действие |
|---|---|---|---|
| Зрелость обучения | exact550 на официальных e1250/e1500/e1750 не достиг трёх чаш | не доказано достижение цели 6000 эпох | заранее зарезервировать полное окно вычислений, сохранять checkpoint по частям и оценивать |
| Распределение данных | в 550 траекториях rescue=257; clean50 и exact550 ведут себя по-разному | возможны смещения профилей / поз / покрытия суставов | провести парную абляцию stock / retry / rescue с одной переменной |
| Выравнивание времени | аудит processed: next-state max error=0, но изменение загрузчика меняет цели | ошибка выравнивания искажает и loss, и замкнутый цикл | зафиксировать официальную семантику, отдельно назвать эксперименты с выравниванием |
| Топология оценки | обычный runner и runner с трассировкой дают разные результаты на одном весе | мелкие выборки нельзя сравнивать напрямую | для финальных ворот использовать официальный persistent runner |
| Разрыв public / private | локально контрольный fresh3=2/3, онлайн T4=25.3/100 | 3 публичных seed не отражают 100 приватных | добавить фиксированную, ранее не просмотренную панель seed |
| Доступность ресурсов | удалённая 4090 отключилась из-за средств; у PRO 6000 ограничения диска и принадлежности GPU | сократилось окно обучения и синхронизации | постоянный диск, предупреждения о балансе, восстанавливаемые checkpoint |
| Процесс отправки | ошибка 403 из-за неверного аккаунта; вторая версия получила 403 после дедлайна | только одна действительная онлайн-квитанция T4 | перед отправкой проверять статус разблокировки и сохранять ID очереди |
| Границы публикации | приватные журналы содержат пути, процессы, учётные данные и крупные файлы | прямое копирование привело бы к утечке секретов или раздуванию репозитория | публиковать только обезличенные сводки и воспроизводимые скрипты |
