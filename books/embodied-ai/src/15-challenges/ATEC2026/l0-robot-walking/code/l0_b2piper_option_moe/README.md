# Каркас отправки L0 B2Piper option-MoE

Этот каталог содержит открытый каркас отправки для трека 1 ATEC2026 онлайн-этапа, L0 «Ходьба робота».

Состав файлов:

- `solution.py`: точка входа, которую вызывает сайт соревнования.
- `solution_rl.py`: загрузка низкоуровневой политики B2Piper, расписание команд скорости, логика option-MoE для manual / rough.
- `requirements.txt`: пустой пример, означает, что дополнительные pip-пакеты не устанавливаются и используется окружение официального образа.

Важно:

1. `policy.pt` сюда не включён. Положите его в этот же каталог: это официальный baseline, собственный экспортированный результат обучения или веса, которые соревнование разрешает публиковать.
2. Код по умолчанию загружает `policy.pt` из этого же каталога и предполагает, что это TorchScript-актёр locomotion `45 -> 12`.
3. `rough option-MoE` — инженерная попытка, сделанная уже после соревнования: сохраняем защищённый prior походки, а на rough-участке переключаем осторожное продвижение и команды выхода из застревания по сегментам score и gate прогресса.
4. Это не решение-чемпион и не гарантия максимального балла. Лучше всего использовать его как пример того, как инкапсулировать стратегию соревнования в `solution.py`.

Структура каталога отправки:

```text
solution.py
solution_rl.py
policy.pt
requirements.txt
```

Локальный дымовой тест:

```bash
python - <<'PY'
import torch
m = torch.jit.load("policy.pt", map_location="cpu")
print(m(torch.zeros(1, 45)).shape)
PY
```

Ожидаемый вывод:

```text
torch.Size([1, 12])
```
