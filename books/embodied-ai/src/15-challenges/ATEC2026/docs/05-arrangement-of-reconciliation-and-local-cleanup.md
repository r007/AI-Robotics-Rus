# 5. Сверка архива и очистка локальных копий

Дата обновления: 31.07.2026

Этот документ отвечает на конкретный вопрос: какие материалы ATEC2026 уже опубликованы в архиве, какие локальные копии можно удалить и насколько можно воспроизвести результаты после удаления.

## 5.1 Соответствие публичного архива

| Категория локальных материалов | Публичное место | Статус |
|---|---|---|
| Учебные материалы GitHub, разбор проблем, контракты наблюдений, скрипты проверки и индекс внешних решений | `datawhalechina/every-embodied`, каталог `15-challenges/ATEC2026/` | отправлено в публичную ветку |
| Снимок публичного исходного кода официального симулятора | исходная папка Task B в наборе данных Datawhale на HF, `source/` | загружено; SHA-256: `84ccfdc3903e4e03a5de8a7dedd90314b15ed09382c136bbeee6a858dae802d9` |
| Превью видео и кадры отладки/оценки Task B | тот же набор на HF, `TaskB-B2Piper/videos/` и `frames/` | загружено; материалы служат только как отладочные и доказательные, а не как официальный результат |
| Официальное руководство участника и обновления | тот же набор на HF, `official_docs/` | загружено; проверены локальные пути, учётные данные и личные адреса электронной почты |
| Исторические плагин и конфигурация XSA из Task E | тот же набор на HF, `historical_task_e/` | загружено; только как историческая справка, не как контроллер Task B |
| Отфильтрованные обучающие данные Task E, код, ассеты робота, публичные логи и веса ACT | репозиторий воспроизведения Task E и модели на HF Datawhale | опубликовано; для отфильтрованных данных приведены SHA-256 фрагментов и скрипты восстановления |
| Китайский Workspace Memory | GitHub `docs/workspace-memory-atec2026-post-match-review.md` и обезличенные копии в двух архивах HF | загружено; оставлены только публичные факты и границы воспроизведения |

## 5.2 Обезличивание

- Из публичных файлов проверки Task E удалены абсолютные пути машины; сохранены только контрольные значения и публичные имена файлов. Значения контрольных сумм не изменялись.
- Исходный Workspace Memory содержал пути машины и подробности окружения, поэтому его не публиковали напрямую. Публичная версия переписана как постсоревновательный разбор на китайском языке без путей, привязанных к машине.
- В видео и скриншотах Task B сохранена пометка «вид окружения только для отладки», и вид окружения не записан в официальный контракт наблюдений.
- Перед публикацией проверены токены, пароли, закрытые ключи, внутренние IP, абсолютные пути машины и URL с аутентификацией.
- Внешние решения участников включены только как публичные ссылки, зафиксированные commit, лицензии и границы переноса. Самооценки не записаны как официальные результаты.

## 5.3 Удалённые локальные копии

Следующие материалы уже имеются в публичном архиве или относятся к невоспроизводимым промежуточным артефактам, поэтому они больше не сохраняются как локальный источник:

- исходные архивы официального кода, официальные руководства, видео и кадры Task B, а также исторические материалы XSA Task E: загруженные локальные копии удалены, остались версии в архиве HF;
- исходный Workspace Memory с путями машины, который уже заменён обезличенной публичной версией;
- около 42 ГБ неудачных и промежуточных checkpoint OpenPI для Task E; публичная инструкция по воспроизведению Task E прямо исключает эти состояния обучения;
- около 6,1 ГБ промежуточных данных конвертации LeRobot для Task E; публичное воспроизведение использует отфильтрованные фрагменты HDF5 на HF, а не эти копии;
- временные файлы staging, возникшие при загрузке на HF, и локальные копии результатов медиа.

Публичный учебный материал на Every Embodied при этом не удалялся, и незаконченные изменения в рабочем дереве, не связанные с ATEC, не затрагивались.

## 5.4 Границы воспроизведения

После удаления локальных копий публичные материалы позволяют воспроизвести:

1. Аудит наблюдений, проверку публикации, манифесты файлов и сравнение с внешними решениями из учебного материала.
2. Поиск и проверку хэшей официального снимка исходного кода, официальных руководств и исторических экспериментальных материалов.
3. Скачивание отфильтрованных данных Task E, объединение фрагментов, проверку хэшей и точку входа в воспроизведение ACT.
4. Чтение отладочных медиа Task B и вывод о том, что «вид окружения не относится к официальным наблюдениям».

Публичные материалы не гарантируют, что одного `git clone` или загрузки с HF будет достаточно для запуска полной оценки Task B. Для полной симуляции всё ещё нужны подходящие Isaac Sim / Isaac Lab, драйверы GPU, зависимости Python, официальный runner и оценщик. Кроме того, публичный архив не утверждает, что существует проверенный checkpoint с полным баллом для Task B.
