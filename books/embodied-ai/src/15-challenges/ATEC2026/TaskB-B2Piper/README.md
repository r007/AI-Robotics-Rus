# ATEC2026 Task B: сбор мусора на B2-Piper

Это учебный материал и разбор проблем для тех, кто будет воспроизводить решение. Task B — не «получить координаты объекта и подойти к ним»: полный замкнутый цикл включает восприятие, локализацию, сближение, управление манипулятором и захватом, подтверждение успешного захвата, перенос, размещение в мусорной корзине и подтверждение состояния оценщиком.

## Главные выводы

| Вопрос | Вывод |
| --- | --- |
| Это про то, как робот-собака подбирает мусор? | Да. Официальное название задачи — Garbage Collection, платформа — B2-Piper. |
| Есть ли в официальном контракте наблюдений глобальная камера окружения, которую можно читать напрямую? | По умолчанию нет. Основные источники наблюдений — головная RGB-D, концевая RGB-D, LiDAR и proprioception. |
| Можно ли напрямую читать координаты объектов? | Во время официального прогона нельзя опираться на истинные позы объектов, random seed или внутренний список объектов симуляции. Положение цели нужно оценивать по допустимым сенсорам. |
| Достаточно ли прийти к целевой точке? | Нет. Сближение, касание, захват, подъём и размещение в корзине подтверждаются отдельно. Небольшое расстояние может быть лишь показателем контакта и не означает физического захвата. |
| Можно ли переносить чужие проекты? | Можно переносить конечные автоматы, визуальное сервоуправление, координацию всего тела, калибровку и методы диагностики; нельзя напрямую переносить ассеты робота, порядок суставов, внешние параметры камер или допущения о награде. |
| Есть ли публичная проверяемая полная реализация Task B с официальным высоким баллом? | В этом архиве такой реализации с проверяемым официальным результатом и весами не найдено. Ближе всего к полному процессу публичный SLAM-форк; см. [сравнение с внешними решениями](./docs/05-comparison-of-excellent-external-solutions.md). |

## Публичный код

| Файл | Назначение |
| --- | --- |
| [`code/inspect_task_b_observation.py`](./code/inspect_task_b_observation.py) | проверяет ключи, типы и формы обезличенного образца observation без запуска симуляции |
| [`code/build_public_manifest.py`](./code/build_public_manifest.py) | формирует манифест публичного каталога с SHA-256 для каждого файла |
| [`code/scan_public_release.sh`](./code/scan_public_release.sh) | проверяет учётные данные, абсолютные пути машины и большие файлы |
| [`code/fetch_reference_repos.sh`](./code/fetch_reference_repos.sh) | загружает публичные справочные репозитории в каталог кеша вне репозитория |
| [`configs/observation_contract.yaml`](./configs/observation_contract.yaml) | декларативная конфигурация границ наблюдений Task B и запрещённых зависимостей |

Эти скрипты — инструменты для учебного материала и публикации; они не являются полноценной стратегией, набирающей баллы. Для реального запуска кода соревнования используйте официальный runner, официальное окружение и официальный оценщик.

## Быстрая проверка

```bash
cd /path/to/every-embodied/15-challenges/ATEC2026/TaskB-B2Piper
bash code/scan_public_release.sh .
python3 code/build_public_manifest.py . --output public_manifest.json
```

Чтобы проверить обезличенный образец observation в формате JSON:

```bash
python3 code/inspect_task_b_observation.py --input observation_sample.json
```

Чтобы получить публичные справочные реализации, используйте каталог вне репозитория:

```bash
bash code/fetch_reference_repos.sh "${TMPDIR:-.reference-cache}"
```
