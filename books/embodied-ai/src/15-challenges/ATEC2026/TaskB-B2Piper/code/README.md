# Лёгкий код Task B

Скрипты здесь нужны для проверки перед публикацией и для проверки интерфейса наблюдений. Они не зависят от Isaac Sim, Isaac Lab, весов моделей или официальных ассетов робота.

## Файлы

- `inspect_task_b_observation.py`: читает обезличенный JSON, выводит дерево наблюдений, имена ключей, типы и формы списков.
- `build_public_manifest.py`: вычисляет SHA-256 для файлов меньше 100 МиБ и формирует манифест публикации.
- `scan_public_release.sh`: проверяет учётные данные, абсолютные пути, сверхбольшие файлы и каталоги кеша.
- `fetch_reference_repos.sh`: загружает открытые референсные репозитории участников в каталог кеша вне основного репозитория, чтобы случайно не закоммитить полный сторонний код.

## Границы использования

Эти скрипты не выполняют управление в Task B, не читают истинные значения симуляции, не генерируют целевые координаты и не утверждают, что захват или укладка в мусорную корзину выполнены. Настоящая policy должна подключаться через официальный runner; нужно заново сверить ключи наблюдений, пространство действий, масштабирование действий и оценщик с той версией официального проекта, которую вы используете.

## Минимальный smoke test

```bash
python3 -m py_compile inspect_task_b_observation.py build_public_manifest.py
bash -n fetch_reference_repos.sh
bash -n scan_public_release.sh
```
