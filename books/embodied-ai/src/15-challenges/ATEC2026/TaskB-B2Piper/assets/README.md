# Открытые материалы

GitHub хранит только описание материалов. Обезличенные превью симуляции и скриншоты лежат в соответствующих каталогах `TaskB-B2Piper/videos/` и `TaskB-B2Piper/frames/` Hugging Face-датасета Datawhale.

Для публикации рекомендуется включать минимум три вида: головной вид, вид с конца манипулятора и вид окружения от третьего лица; все они должны быть синхронизированы по одному `episode_id` или времени симуляции. Видео окружения обязательно помечается в описании как отладочный вид и не должно создавать впечатления, будто это вход policy.

Все текущие медиа — это локальные превью для отладки и оценки, а не доказательство результата официального рейтинга. Вид сверху и глобальный вид используют privileged trace и служат только для объяснения причин сбоев.
