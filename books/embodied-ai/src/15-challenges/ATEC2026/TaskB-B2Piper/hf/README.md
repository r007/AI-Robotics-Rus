# Публичный архив Hugging Face

Соответствующий публичный репозиторий наборов данных Datawhale:

- [Datawhale/atec2026-task-b-reproducibility](https://huggingface.co/datasets/Datawhale/atec2026-task-b-reproducibility)

## Границы содержимого

Архив на HF соответствует учебному материалу на GitHub: он содержит лёгкие документы, конфигурации, скрипты проверки, описание границ результатов и проверенные публичные крупные файлы. В него не входят:

- внешние наборы данных без разрешения на повторное распространение;
- приватные веса моделей, необработанные приватные журналы и неразрешённые исходные видео соревнования;
- токены доступа, абсолютные пути машины и внутренние адреса служб.

Дополнительно загружены два набора материалов, которые можно воспроизводить публично:

- `source/ATEC2026_Simulation_Challenge_20260518.zip`: снимок публичного репозитория официального проекта от 18.05.2026 с ассетами робота и baseline; сохранена официальная лицензия MIT (LICENSE).
- `TaskB-B2Piper/videos/` и `TaskB-B2Piper/frames/`: локальные превью отладки и оценки Task B; все помечены как debug-only и не означают официальный балл или полный захват.

SHA-256 снимка исходного кода: `84ccfdc3903e4e03a5de8a7dedd90314b15ed09382c136bbeee6a858dae802d9`.

Для всех загруженных крупных файлов в каталоге HF отдельно указаны источник, версия и SHA-256; в обычную историю Git на GitHub они не помещались. Полный список загрузок и локальных удалений — в [сверке архива и очистке локальных копий](https://github.com/datawhalechina/every-embodied/blob/main/15-challenges/ATEC2026/docs/05-arrangement-of-reconciliation-and-local-cleanup.md) (в этом репозитории файл называется `docs/05-arrangement-of-reconciliation-and-local-cleanup.md`).

## Воспроизведение из GitHub

```bash
git clone https://github.com/datawhalechina/every-embodied.git
cd every-embodied/15-challenges/ATEC2026/TaskB-B2Piper
bash code/scan_public_release.sh .
python3 code/build_public_manifest.py . --output public_manifest.json
```

## Получение с HF

```bash
git clone https://huggingface.co/datasets/Datawhale/atec2026-task-b-reproducibility
```

Учебные файлы в репозитории HF не заменяют официальное окружение Task B. Сначала установите окружение по официальному репозиторию, и только потом используйте этот каталог для проверки границ и записи экспериментов.

## Границы воспроизводимости

После загрузки публичный архив позволяет воспроизвести учебные материалы по наблюдениям, проверку публикации, поиск снимка официального исходного кода и чтение видео как доказательств. Полная симуляция Task B по-прежнему требует установленных Isaac Sim / Isaac Lab, соответствующих версии официального проекта, драйверов GPU и окружения Python. Архив HF не содержит приватных кешей окружения и не утверждает, что достаточно только `git clone`, чтобы запустить симуляцию без дополнительной настройки.

Рекомендуется зафиксировать версию официального исходного кода: `4000378a9a6fc6ce3e57bcdd20a1582f6854e0dc`. При использовании снимка с HF опирайтесь на `readme.md`, `LICENSE` и задачные скрипты внутри архива.

## Другие публичные материалы соревнования

Чтобы локальные материалы не были разбросаны, в корне HF также сохранены:

- `official_docs/`: официальное руководство участника онлайн-этапа ATEC2026 и описания обновлений; при проверке не найдено локальных путей, учётных данных или личных адресов электронной почты.
- `historical_task_e/`: архив плагина XSA для Task E и конфигурации обучения; это историческая экспериментальная справка, а не policy для Task B и не надёжное решение с высоким баллом.

Эти материалы отделены от кода Task B: читатель не должен переносить фиксированную схему манипуляции Task E напрямую как контроллер сбора мусора для B2-Piper.
