# Лёгкий код ATEC2026

Здесь хранится лёгкий код, который можно сразу включить в учебный репозиторий. В нём нет Isaac Sim, весов моделей, обучающих кешей и полных сторонних репозиториев.

## Файлы

- `taskd_reference_adapter.py`: демонстрирует адаптацию действий в стиле Logic-TARS из 16D locomotion action в 24D official action, а также разбиение этапов Task D по score.
- `external_repo_audit/clone_references.sh`: загружает внешние открытые референсные репозитории по фиксированному commit.
- `external_repo_audit/external_repos.yaml`: список репозиториев, commit, лицензий и назначения миграции.

## Границы

Эти файлы нужны, чтобы понять интерфейсы и организацию материалов для воспроизведения. Это не официальный пакет для отправки и не содержит policy, которая гарантирует высокий балл.
