# Индекс внешних решений

Этот каталог не копирует полный код сторонних репозиториев. Он фиксирует ссылки на upstream, зафиксированные commit, лицензии и границы переноса. Так сохраняются авторство и прослеживаемость версий, а код для разных роботов и разных версий симуляции не принимается за готовое решение Datawhale для отправки.

## Logic-TARS

- Upstream-репозиторий: [Logic-TARS/ATEC2026](https://github.com/Logic-TARS/ATEC2026)
- Зафиксированный commit: `b78c4afd1b84302fe8f88bcfd287eac64c33692c`
- Лицензия: MIT, действует `LICENSE` upstream-репозитория
- Ключевые файлы: `README.zh-CN.md`, `submission/solution.py`, `scripts/train/`, `scripts/export/`
- Направление: Task D, B2W, толкание ящика и преодоление препятствий
- Что можно перенести: интерфейс 61D/16D, адаптер 16D→24D, конечный автомат стадий, обнаружение коробки по LiDAR, коррекция курса, восстановление после зависания
- Что нельзя считать само собой разумеющимся: что checkpoint работает, что пороги оценки никогда не меняются, что интерфейсы B2Piper и B2wPiper совпадают
