# Веб-управление Joy-Con для Robosuite

Браузерная система дистанционного управления Nintendo Switch Joy-Con. Через WebSocket она в реальном времени связывает контроллер с симуляцией Robosuite и поддерживает управление одной или двумя руками, несколькими роботами и удалённое управление по локальной сети.

---

## 🌟 Основные особенности

- ✅ **Браузер как пульт**: ввод с Joy-Con читается через Gamepad API, интерфейс опрашивает его с частотой 60 Гц.
- ✅ **Двусторонняя связь в реальном времени**: данные по WebSocket с низкой задержкой передаются в серверную часть на Python.
- ✅ **Полная поддержка Robosuite**: используется официальный интерфейс `Device`, поддерживаются контроллеры OSC и Whole Body.
- ✅ **Один или два Joy-Con**: по умолчанию одна рука, но можно управлять двумя руками — левым и правым контроллером.
- ✅ **Графический мониторинг**: в реальном времени показываются кнопки, стики и состояние соединения.
- ✅ **Кроссплатформенность**: Linux, Windows (включая WSL2) и macOS; для подключения Joy-Con достаточно Bluetooth.

## ⚡ Быстрый старт за 5 минут

> Нужны Python ≥ 3.8, Bun или Node.js и Joy-Con с Bluetooth. (Рекомендуется.)

1. **Получите код и установите зависимости**
   ```bash
   cd /home/user/17robo/robosuite-joycon-web
   bun install
   pip install -r requirements.txt

   # Установите robosuite (нужно при первом запуске)
   cd /home/user/17robo/robosuite-joycon
   pip install -e .
   cd /home/user/17robo/robosuite-joycon-web
   ```

2. **Запустите самопроверку без рендеринга (подходит для WSL и серверов)**
   ```bash
   python test_server_no_render.py
   ```
   Сообщение `✅ 所有测试通过!` («все тесты пройдены») означает, что логика серверной части работает.

3. **Подключите Joy-Con по Bluetooth**
   - Долго удерживайте кнопку синхронизации на боковой стороне Joy-Con, пока индикатор быстро мигает.
   - В настройках Bluetooth системы выберите `Joy-Con (R)` или `Joy-Con (L)`.

4. **Запустите сервер и интерфейс**
   ```bash
   # Терминал 1: одиночный контроллер, среда по умолчанию (Lift + Panda)
   ./start_single.sh

   # Терминал 2: интерфейс React
   bun run dev
   ```
   Откройте в браузере адрес из подсказки (по умолчанию http://localhost:5173).

5. **Начните управление**
   - На веб-странице нажмите «Подключиться к серверу».
   - Нажмите любую кнопку на Joy-Con, чтобы активировать геймпад.
   - Управляйте роботом в реальном времени.

> Без монитора / в WSL: если рендеринг неудобен, можно установить в `server.py` параметр `has_renderer = False`.

## 🎮 Назначение кнопок (раскладка Joy-Con по умолчанию)

| Ввод | Функция |
|------|---------|
| Левый стик X / Y | Перемещение захвата по X / Y |
| R (правый контроллер) / L (левый контроллер) | Подъём захвата (Z+) |
| Нажатие на стик | Опускание захвата (Z−) |
| Правый стик X | Поворот Yaw |
| Правый стик Y | Поворот Pitch |
| SL / SR | Тонкая настройка Roll (для правого контроллера — по/против часовой стрелки, для левого — наоборот) |
| ZR / ZL | Переключение захвата «открыть / закрыть» (одно нажатие — смена состояния) |
| + (Plus) | Сброс среды |
| HOME | Возврат позы в исходное смещение |
| A / Y | Зарезервированные флаги событий (совместимы с интерфейсом исходного JoyConController) |

Все входы в `JoyconWebController` проходят подавление дребезга и нормализацию; выход сервера остаётся 6+1-мерным вектором действий, полностью совместимым с официальными контроллерами Robosuite.

> ℹ️ По умолчанию браузер читает кнопки и стики только через Gamepad API, поэтому для регулировки ориентации используйте правый стик и SL/SR. Если включить экспериментальную функцию WebHID ниже, можно будет управлять ориентацией захвата, поворачивая сам Joy-Con, как в нативном контроллере.

### Экспериментальная поддержка IMU через WebHID

- В Chrome или Edge (нужен HTTPS или `localhost`) нажмите кнопку «Подключить IMU Joy-Con» — датчики Joy-Con станут доступны через WebHID.
- После подключения страница в реальном времени показывает Roll / Pitch / Yaw и передаёт их на сервер, так что ориентацией захвата можно управлять поворотом Joy-Con.
- Сейчас в одном сеансе браузера поддерживается только один Joy-Con; чтобы переключиться, обновите страницу и подключитесь заново.
- В браузерах без WebHID сохраняется режим управления ориентацией стиками и SL/SR.

## 🛠️ Частые проблемы и диагностика

| Проблема | Причина | Решение |
|----------|---------|---------|
| `Action vector ... got 12` | Неверная размерность действия | Исправлено в текущей версии; используйте актуальный `server.py` |
| Сервер зависает в WSL | Блокировка из-за отсутствия графического рендеринга | Отключите рендеринг: `has_renderer=False`, или настройте X11 / VNC |
| Интерфейс не видит Joy-Con | Геймпад не активирован | Нажмите любую кнопку в браузере; обновите страницу; проверьте Bluetooth |
| Не подключается WebSocket | Порт занят или сервис не запущен | Проверьте лог сервера; `lsof -i :8765`; `pkill -f "python server.py"` |
| Большая задержка управления | Сеть или загруженный процессор | Запускайте локально; закройте лишние программы; удалённо — только по локальной сети |

> Совет новичкам: сначала запустите `python test_server_no_render.py`, убедитесь, что базовое управление работает, и только потом подключайте рендеринг и интерфейс.

## 🔍 Техническая реализация и исправления

- Полностью повторяет логику `robosuite.devices.Device`: `input2action`, `get_arm_action`, конечный автомат и преобразование систем координат остаются прежними.
- Выходной вектор действий фиксированной размерности: 6 (поза захвата) + 1 (захват); совместим с контроллерами OSC и Whole Body IK.
- Для устранения дребезга кнопок используется определение фронта нажатия; переключение захвата ZR/ZL.
- `test_server_no_render.py` проверяет вектор действий, возврат награды и непрерывное управление.
- Скрипты запуска `start_single.sh` и `start_bimanual.sh` объединяют частые параметры для удобного развёртывания.
