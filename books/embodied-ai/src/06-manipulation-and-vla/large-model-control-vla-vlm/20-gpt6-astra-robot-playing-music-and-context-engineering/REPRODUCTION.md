# Журнал запусков и проверка воспроизводимости

Записи относятся к трём случаям: статическая постановка рук, непрерывное перемещение инструмента с продолжением игры и публичное упражнение этой главы. Завершение управления, совпадение положения запястий и музыкальная точность оцениваются отдельными метриками.

## Готовая демонстрация: постановка рук после перемещения фортепиано

В одинаковом начальном состоянии фортепиано сдвигается по мировой оси Y на 6 сантиметров; восстановление длится 1,6 секунды:

| Метод | Постановка выполнена | Максимальная конечная ошибка положения | Новые выводы G0.5 |
| --- | --- | --- | --- |
| IK | Да | 0,0050 миллиметра | 0 |
| G0.5 + IK | Да | 0,0553 миллиметра | 4 |

Оба метода завершили совмещение. Результат показывает, что предложение G0.5 может подключаться к существующему контроллеру, но не доказывает уменьшения геометрической ошибки. Интеграл изменения команд на пути G0.5 + IK составил 0,00579 рад·с; во время исполнения состояния суставов не переписывались покадрово.

## Готовая демонстрация: продолжение игры после перемещения

Во время непрерывной сессии фортепиано по мировой оси Y смещается на −4 сантиметра и проходит такие этапы:

| Этап | Время в симуляции |
| --- | --- |
| Первая половина игры | 0–18,68 с |
| Поднятие рук | 18,68–19,68 с |
| Перемещение инструмента | 19,68–20,48 с |
| Восстановление G0.5 + IK | 20,48–22,08 с |
| Опускание рук | 22,08–23,08 с |
| Продолжение игры | 23,08–56,38 с |

Сессия выполнилась полностью; на этапе восстановления было 4 новых вывода модели; максимальная остаточная ошибка положения запястья — около 0,098 миллиметра, остаточная ошибка ориентации — около 0,00177 рад; число контактов между двумя кистями — 0; конечное состояние суставов при воспроизведении совпало с исходным исполнением.

В музыкальной проверке 100 целевых начал звуков при допуске 120 миллисекунд совпали с 90 фактически зафиксированными; строгая музыкальная проверка не пройдена. Звук в видео создаётся по фактическим событиям нажатия клавиш; во время вывода модели часы симуляции приостанавливаются.

## Публичное упражнение этой главы

Выполнено 5–6 октября 2026 года в отдельном каталоге с публичными скриптами главы, существующей моделью и отдельным окружением:

- `piano_context.py prepare` и проверка примера плана прошли; платных запросов к API не делалось.
- 146 существующих проверок прогона воспроизведения и логики управления прошли.
- Генерация сайта документации прошла; глава попала в оглавление.
- Упражнение на 14 нот выполнено полностью; проверка контактов не показала столкновения рук, но остались одна пропущенная нота и отдельные отклонения в начале звуков, поэтому строгая музыкальная проверка не пройдена.

Перемещение в упражнении запущено с параметрами из README (горизонтально −2 сантиметра, вес позы 0,1). Сессия управления выполнилась полностью за **13,51 секунды**: без остановки на постановке или из-за контакта. Во время восстановления выполнено 4 новых вывода модели; максимальная ошибка положения запястья — **0,0617 миллиметра**, ошибка ориентации — **0,000169 рад**, интеграл изменения команд из-за модели — **0,0193 рад·с**, число столкновений кистей — 0, разница конечного состояния при проверочном воспроизведении — 0.

Зафиксировано 13 фактических начал звуков; из 14 целевых 7 совпали в пределах допуска 120 миллисекунд, строгая музыкальная проверка не пройдена. Это упражнение нужно для воспроизведения всего процесса управления и для продолжения отладки аппликатуры.

В этой версии в решение восстановления добавлено ограничение диапазона движения: прежде ошибка возникала из-за покомпонентной обрезки суставов и смещала совмещение запястья. Время опускания рук автоматически увеличивается до 1,19 секунды, одновременно обновляется время пауз в партитуре. Критерий восстановления остаётся прежним: за последние 0,2 секунды ошибка положения не больше 5 миллиметров, ошибка ориентации не больше 0,05 рад.

## Какие поля отчёта читать

| Поле | Значение |
| --- | --- |
| `playback_completed` | Выполнен ли процесс управления до конца |
| `safety_stop` | Не была ли сессия прервана по условиям постановки или контакта |
| `model_calls_during_session` | Фактическое число новых выводов модели в сессии |
| `model_induced_command_distance_rad_seconds` | Изменение команд, вызванное предложением модели |
| `recovery_final_error` | Остаточная ошибка положения и ориентации запястий после перемещения |
| `onset_metrics` | Совпадение фактических начал звуков с целевыми |
| `performance_passed` | Результат строгой музыкальной проверки |
| `audit_final_qpos_error` | Разница конечного состояния между проверочным воспроизведением и фактическим исполнением |

При повторном воспроизведении сохраняйте собственные отчёты и не считайте числа одного запуска гарантией для других роботов, произведений и аппаратуры.
