# Домашний помощник по запасам на OpenClaw

Этот цикл учебных материалов рассчитан на читателей, у которых уже есть базовое окружение с OpenClaw, Feishu (Lark) и роботом на платформе D-Robotics. Цель — соединить в одну воспроизводимую цепочку управление домашними запасами, напоминания о низком остатке, синхронизацию со многомерной таблицей Feishu и задачи роботизированной руки.

## Что входит в эту тему

1. Способы подключения фронтенда и бэкенда OpenClaw и настройки Feishu
2. Модель домашних запасов и напоминания о низком остатке
3. Синхронизация со многомерной таблицей Feishu
4. Отображение помощника по запасам во фронтенде
5. Какие локальные крупные файлы и редакторы сцен исключать при публикации

## Границы публикации

При публикации оставляем только учебные Markdown-файлы, небольшое число скриптов, исходный код фронтенда и схемы. Не выкладываем редактор сцен, веса моделей, кеши, загруженные пакеты и временные файлы отладки.
