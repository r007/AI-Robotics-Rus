# Запасы и синхронизация со многомерной таблицей

В этой главе состояние запасов домашнего помощника синхронизируется со многомерной таблицей Feishu. Читателю не нужно сначала понимать весь процесс работы руки: достаточно знать, как формируется снимок запасов, как он записывается в таблицу Feishu и какие настройки проверять при сбое.

## Что должно получиться после главы

Читатель должен уметь:

1. Понимать структуру данных снимка запасов домашнего помощника
2. Создать для синхронизации многомерную таблицу Feishu
3. Настроить `appToken` и `tableId`
4. Вручную запустить одну синхронизацию и проверить результат

## Поля таблицы

Рекомендуемые поля многомерной таблицы:

| Поле | Значение |
| --- | --- |
| `SKU` | уникальный идентификатор товара |
| `物品` (название товара) | отображаемое название |
| `剩余数量` (остаток) | текущее количество на складе |
| `阈值` (порог) | порог низкого остатка |
| `建议补货` (рекомендуемое пополнение) | рекомендуемое количество для пополнения |
| `单位` (единица) | штуки, бутылки, блоки и т. п. |
| `位置` (местоположение) | место хранения в доме |
| `状态` (статус) | норма или низкий остаток |
| `购买链接` (ссылка на покупку) | вход для закупки |
| `下单链接` (ссылка на заказ) | ссылка для заказа, которую формирует OpenClaw |
| `更新时间` (время обновления) | время последнего обновления |

Примечание: в первом столбце указаны названия полей так, как они заданы в коде синхронизации. Если вы переводите интерфейс, переименовывайте поля одновременно в таблице Feishu и в коде.

## Где задать конфигурацию

Для синхронизации со многомерной таблицей нужны два значения:

```env
OPENCLAW_FEISHU_BITABLE_APP_TOKEN=
OPENCLAW_FEISHU_BITABLE_TABLE_ID=
```

Если не хочется задавать переменные окружения, их можно записать в `~/.openclaw/openclaw.json` по пути `channels.feishu.inventoryBitable`.

## Частые проблемы

- `feishu bitable sync not configured` (синхронизация со многомерной таблицей Feishu не настроена): обычно не заданы `appToken` или `tableId`, либо программа не смогла прочитать конфигурационный файл.
- `Access denied` (доступ запрещён): обычно у приложения Feishu не открыты права на многомерную таблицу.
- Python не читает `openclaw.json`: проверьте, нет ли в файле UTF-8 BOM; в Windows лучше сохранять UTF-8 без BOM.
