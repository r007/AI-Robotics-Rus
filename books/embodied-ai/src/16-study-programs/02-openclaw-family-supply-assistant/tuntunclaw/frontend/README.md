# Описание фронтенда

Здесь находится статический веб-интерфейс OpenClaw.

## Файлы

- `index.html`
- `styles.css`
- `app.js`

## Способ использования

Можно открыть `index.html` прямо в браузере или запустить локальный сервис FastAPI через `main.py` в корне репозитория и открыть страницу в браузере.

По умолчанию интерфейс работает в режиме mock (имитации). Когда появится настоящий бэкенд, адрес сервиса задаётся кнопкой `API` в верхней части страницы.

Фронтенд рассчитывает на следующие вызовы:

- `POST /api/command`
- `GET /api/session/:id`
- `GET /api/session/:id/events`

## Примечания

- Страница оформлена в тёмных тонах с яркими надписями.
- В поле команд `Enter` отправляет запрос, `Shift+Enter` переносит строку.
- Заранее подготовлены типовые тестовые команды для быстрой проверки.
