# Проблемы с доступом в интернет через виртуальную сетевую карту

Источник: https://linux.do/t/topic/276425

1. Нажмите `Win+R` и введите `secpol.msc`, чтобы открыть «Локальную политику безопасности».

   ![Скриншот 1](https://linux.do/uploads/default/original/4X/e/5/6/e56fe9c7b8dc8ff1419d8a7db68c48ca10fae572.png)

2. Откройте раздел «Политики диспетчера списка сетей» и дважды щёлкните **Mihomo**.

   ![Скриншот 2](https://linux.do/uploads/default/optimized/4X/0/c/6/0c69fe3e156b6c7a55a3d014048c00c2e39a71b6_2_690x495.png)

3. В поле «Расположение сети» выберите **Частная**, затем перезапустите Clash. После этого интернет должен работать.

   [![Скриншот 3](https://linux.do/uploads/default/optimized/4X/f/f/2/ff24b5001969f869b9257fc84573f03257c4fed7_2_456x500.png)](https://linux.do/uploads/default/original/4X/f/f/2/ff24b5001969f869b9257fc84573f03257c4fed7.png)
