# Указание пути установки окружений conda

Окружения conda по умолчанию создаются в домашнем каталоге, и на системном диске может не хватить места для больших окружений (например, для PyTorch и CUDA). Ниже два способа хранить окружения на диске данных.

### Способ 1: настройка `envs_dirs` (рекомендуется)

Можно указать conda, что каталог `/path/to/data/envs` тоже предназначен для окружений. После этого окружения создаются и активируются по имени, а файлы фактически лежат на диске данных.

**Порядок действий:**

1. **Добавьте путь в конфигурацию conda**:
    ```bash
    # Добавляем каталог диска данных в начало списка путей поиска окружений
    conda config --add envs_dirs /path/to/data/envs
    ```

2. **Проверьте настройку**:
    ```bash
    conda info
    # Смотрим раздел "envs directories" в выводе
    # Убедитесь, что /path/to/data/envs стоит первым
    ```

3. **Создайте окружение по имени, как обычно**:
    Поскольку путь диска данных стоит первым, conda по умолчанию создаст окружение там.
    ```bash
    conda create -n openpi-server python=3.11 -y
    ```

4. **Активируйте окружение по имени, как обычно**:
    ```bash
    conda activate openpi-server
    ```

Так решается проблема места на диске (окружения хранятся на диске данных), а команды остаются короткими.

---

### Способ 2: alias в оболочке

Если не хотите менять конфигурацию conda, добавьте alias в свой `~/.bashrc`:

1. Отредактируйте `.bashrc`:
    ```bash
    echo 'alias act_openpi="conda activate /path/to/data/envs/openpi-server"' >> ~/.bashrc
    source ~/.bashrc
    ```
2. Теперь достаточно ввести `act_openpi`, чтобы активировать окружение.

**Итог:** рекомендуется **способ 1**. Это решение действует постоянно, и все последующие большие окружения тоже будут создаваться на диске данных.
