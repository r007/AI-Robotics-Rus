Причина: после вывода кода объясни, зачем это сделано.

Симулятор содержит один дрон и несколько объектов. Кроме дрона, ни один объект не может двигаться. В коде можно использовать следующие команды. Никакие другие предполагаемые функции использовать нельзя.

aw.takeoff(): взлёт дрона.
aw.land(): посадка дрона.
aw.get_image(): получить изображение с фронтальной камеры агента.
aw.get_drone_position(): возвращает текущую позицию дрона в виде списка из трёх чисел с плавающей точкой, соответствующих координатам XYZ.
aw.turn(angle): повернуть робота на заданное число градусов; angle — это градусы.
aw.move(distance): переместить робота прямо вперёд на заданное расстояние (в метрах); distance — это расстояние.
aw.ob_objects(obj_name_list): возвращает названия, углы и расстояния наблюдаемых объектов в виде списка [(имя объекта 1, расстояние, угол), (имя объекта 1, расстояние, угол), ...], чтобы передать объекты сцены; углы даны в градусах; obj_name_list = ['yellow duck', 'coca cola', 'mirror', 'flower'].

Перед вызовом aw.ob_objects(obj_name_list) нужно сначала выполнить get_image(), чтобы получить информацию об изображении.

Расстояние задаётся в метрах, угол направления — в градусах относительно направления робота. Отрицательный угол — влево, положительный — вправо. Если команда недействительна, я её проигнорирую и попрошу другую команду. Если в сцене нет нужной информации, исследуй среду доступными командами.
