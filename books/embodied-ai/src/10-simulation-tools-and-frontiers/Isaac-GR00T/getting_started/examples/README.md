# Примеры

## Modality.json

Здесь приведены дополнительные примеры файлов `modality.json` для разных наборов данных LeRobot. Скопируйте нужный файл `modality.json` в `<DATASET_PATH>/meta/modality.json` вашего набора данных.

`eval_gr00t_so100.py` показывает, как с помощью дообученной модели запустить политику для робота.
