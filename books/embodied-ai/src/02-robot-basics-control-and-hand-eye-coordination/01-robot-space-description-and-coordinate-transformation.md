# Описание пространства робота и преобразование координат

#### 1. Введение

В робототехнике описание положения и ориентации (позы) объекта в пространстве — основа всех последующих расчётов. В этом модуле подробно рассказано, как описывать движение твёрдого тела с помощью матрицы вращения и вектора переноса, а также как объединить их в **однородную матрицу преобразования (Homogeneous Transformation Matrix)**.

#### 2. Основная теория

##### 2.1 Матрица вращения (Rotation Matrix)

Вращение в двумерном или трёхмерном пространстве описывается ортогональной матрицей. Например, поворот на угол $\theta$ вокруг оси $Z$ задаётся матрицей $R_z(\theta)$:

$$R_z(\theta) = \begin{bmatrix} \cos\theta & -\sin\theta & 0 \\ \sin\theta & \cos\theta & 0 \\ 0 & 0 & 1 \end{bmatrix}$$

##### 2.2 Однородное преобразование (Homogeneous Transformation)

Чтобы объединить вращение ($R$, $3\times3$) и перенос ($P$, $3\times1$) в одну линейную операцию, вводится однородная матрица преобразования $T$ размером $4\times4$:

$$T = \begin{bmatrix} R & P \\ 0 & 1 \end{bmatrix} = \begin{bmatrix} r_{11} & r_{12} & r_{13} & p_x \\ r_{21} & r_{22} & r_{23} & p_y \\ r_{31} & r_{32} & r_{33} & p_z \\ 0 & 0 & 0 & 1 \end{bmatrix}$$

#### 4. Проверка на Python

Код показывает, как с помощью `numpy` построить однородную матрицу преобразования и перевести точку из локальной системы координат в глобальную.

```python
import numpy as np

def get_rotation_z(theta_deg):
    """Создаёт матрицу поворота вокруг оси Z"""
    theta = np.radians(theta_deg)
    c, s = np.cos(theta), np.sin(theta)
    return np.array([
        [c, -s, 0],
        [s,  c, 0],
        [0,  0, 1]
    ])

def get_homogeneous_matrix(R, P):
    """Объединяет поворот и перенос в однородную матрицу 4x4"""
    T = np.eye(4)
    T[:3, :3] = R
    T[:3, 3] = P
    return T

# --- Моделирование сцены ---
# Система координат {B} концевого звена робота относительно базовой системы {A}:
# 1. Поворот вокруг оси Z на 90 градусов
# 2. Перенос на 2 м по оси X и на 1 м по оси Y

# 1. Задаём поворот и перенос
R_AB = get_rotation_z(90)
P_AB = np.array([2, 1, 0])

# 2. Строим матрицу преобразования T_AB
T_AB = get_homogeneous_matrix(R_AB, P_AB)

# 3. Задаём точку P на концевом звене (в системе {B} её координаты [1, 0, 0])
P_B = np.array([1, 0, 0, 1])  # однородные координаты

# 4. Вычисляем положение этой точки в базовой системе {A}
P_A = T_AB @ P_B

print("Матрица преобразования T_AB:\n", T_AB)
print("-" * 30)
print(f"Точка в локальной системе B: {P_B[:3]}")
print(f"Точка в глобальной системе A: {P_A[:3]}")

# Ожидаемый результат:
# После поворота на 90 градусов ось X системы B указывает вдоль оси Y системы A.
# Начало системы B находится в точке (2, 1) системы A.
# Точка (1, 0) в системе B — это шаг на 1 м вдоль оси X системы B,
# что соответствует шагу на 1 м вдоль оси Y системы A.
# Итоговое положение: (2, 1 + 1) = (2, 2).
```
