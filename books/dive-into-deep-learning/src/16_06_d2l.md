# 16.6 Документация по API пакета `d2l`

Реализации перечисленных ниже членов пакета `d2l`, а также их определения и объяснения можно найти в [исходных файлах](https://github.com/d2l-ai/d2l-en/tree/master/d2l).

> **Примечание переводчика.** В исходной книге этот раздел собирается автоматически (Sphinx autodoc) из строк документации пакета `d2l`. Здесь перечислены только имена членов пакета. Перечисленных классов нет в файлах `d2l/*.py` репозитория, на котором основан перевод; их определения находятся в пакете `d2l` английской версии книги (ссылка выше).

**MXNet:** модуль `d2l.mxnet`.

**PyTorch:** модуль `d2l.torch`.

**TensorFlow:** модуль `d2l.tensorflow`.

**PaddlePaddle:** модуль `d2l.paddle`.
