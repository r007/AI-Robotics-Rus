# Погружение в глубокое обучение

Эта книга — русскоязычное издание учебника по глубокому обучению, основанного на китайской версии «Dive into Deep Learning». Оригинал сочетает объяснения, математику и исполняемый код на Python: идея в том, чтобы сначала показать, как работает метод, а затем сразу применить его на реальных данных.

Учебник начинается с основ: данных и предварительных знаний (линейная алгебра, математический анализ, теория вероятностей), затем рассматриваются линейные модели, многослойные перцептроны, вычислительные аспекты обучения, свёрточные и рекуррентные сети, механизмы внимания, методы оптимизации, вычислительную производительность, компьютерное зрение и обработку естественного языка. Код приведён для нескольких фреймворков глубокого обучения.

Книга распространяется по лицензии CC BY-SA 4.0. Авторство оригинала, лицензия и происхождение материалов описаны в файлах [NOTICE.md](../NOTICE.md) и [PROVENANCE.md](../PROVENANCE.md).

Перевод выполнен полностью: предисловие, установка, обозначения, главы 1–15, приложение «Инструменты для глубокого обучения» и список литературы. Рисунки и таблицы пронумерованы по разделам, как в оригинале. Сведения о том, что изменено относительно оригинала, см. в файле [PROVENANCE.md](../PROVENANCE.md).
