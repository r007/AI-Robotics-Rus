# 2.1 Манипулирование данными

Чтобы выполнять различные операции с данными, нам нужен способ их хранить и обрабатывать.
Обычно нужно сделать две важные вещи: (1) получить данные; (2) обработать их после того, как они попали в компьютер.
Без способа хранить данные получать их не имеет смысла.

Для начала познакомимся с $n$-мерными массивами, которые также называют *тензорами* (tensor).
Тем, кто пользовался пакетом NumPy для Python, этот раздел будет знаком.
Какой бы фреймворк глубокого обучения ни использовался, его *класс тензоров* (в MXNet это `ndarray`, в PyTorch и TensorFlow — `Tensor`) похож на `ndarray` из NumPy.
Однако фреймворки глубокого обучения предлагают несколько важных возможностей, которых нет у `ndarray` из NumPy:
во-первых, они хорошо поддерживают ускоренные вычисления на GPU, тогда как NumPy работает только на CPU;
во-вторых, класс тензоров поддерживает автоматическое дифференцирование.
Эти возможности делают класс тензоров более подходящим для глубокого обучения.
Если не оговорено иное, под тензорами в этой книге понимаются экземпляры класса тензоров.

## 2.1.2 Операторы

Нас интересуют не только чтение и запись данных.
Мы хотим выполнять над данными математические операции. Самые простые и полезные из них — *поэлементные* (elementwise) операции.
Они применяют стандартный скалярный оператор к каждому элементу массива.
Для функций, которые принимают два массива, поэлементная операция применяет бинарный оператор к каждой паре элементов, стоящих в одинаковых позициях двух массивов.
Поэлементную функцию можно построить на основе любой функции, которая переводит скаляр в скаляр.

В математической записи унарный скалярный оператор (принимающий один аргумент) обозначается как $f: \mathbb{R} \rightarrow \mathbb{R}$.
Это значит, что функция отображает любое вещественное число ($\mathbb{R}$) в другое вещественное число.
Аналогично бинарный скалярный оператор (принимающий два аргумента) обозначается как $f: \mathbb{R}, \mathbb{R} \rightarrow \mathbb{R}$.
Для любых двух векторов $\mathbf{u}$ и $\mathbf{v}$ одинаковой формы и бинарного оператора $f$ мы получаем вектор $\mathbf{c} = F(\mathbf{u},\mathbf{v})$.
Вычисляется он так: $c_i \gets f(u_i, v_i)$, где $c_i$, $u_i$ и $v_i$ — элементы векторов $\mathbf{c}$, $\mathbf{u}$ и $\mathbf{v}$ соответственно.
Здесь мы превращаем скалярную функцию в поэлементную векторную операцию и получаем функцию $F: \mathbb{R}^d, \mathbb{R}^d \rightarrow \mathbb{R}^d$, которая возвращает вектор.

Для любых тензоров одинаковой формы **стандартные арифметические операторы (`+`, `-`, `*`, `/` и `**`) выполняются поэлементно**.
Поэлементную операцию можно выполнять над любыми двумя тензорами одинаковой формы.
В примере ниже запятая перечисляет кортеж из 5 элементов, каждый из которых — результат поэлементной операции.

**MXNet:**

```python
x = np.array([1, 2, 4, 8])
y = np.array([2, 2, 2, 2])
x + y, x - y, x * y, x / y, x ** y  # Оператор ** — возведение в степень
```

**PyTorch:**

```python
x = torch.tensor([1.0, 2, 4, 8])
y = torch.tensor([2, 2, 2, 2])
x + y, x - y, x * y, x / y, x ** y  # Оператор ** — возведение в степень
```

**TensorFlow:**

```python

y = tf.constant([2.0, 2, 2, 2])
x + y, x - y, x * y, x / y, x ** y  # Оператор ** — возведение в степень
```

**PaddlePaddle:**

```python
x = paddle.to_tensor([1.0, 2, 4, 8])
y = paddle.to_tensor([2, 2, 2, 2])
x + y, x - y, x * y, x / y, x**y  # Оператор ** — возведение в степень
```

**Также можно *объединять* (concatenate) несколько тензоров**,
укладывая их встык в один больший тензор.
Нужно лишь передать список тензоров и указать, по какой оси их соединять.
В примере ниже показано, что происходит при соединении двух матриц по строкам (вдоль оси 0, первого элемента формы) и по столбцам (вдоль оси 1, второго элемента формы).
Длина первого выходного тензора по оси 0 (6) равна сумме длин входных тензоров по оси 0 ($3 + 3$); длина второго выходного тензора по оси 1 (8) равна сумме длин входных тензоров по оси 1 ($4 + 4$).

```python
Y = np.array([[2, 1, 4, 3], [1, 2, 3, 4], [4, 3, 2, 1]])

```

**PyTorch:**

```python

Y = torch.tensor([[2.0, 1, 4, 3], [1, 2, 3, 4], [4, 3, 2, 1]])
torch.cat((X, Y), dim=0), torch.cat((X, Y), dim=1)
```

**TensorFlow:**

```python
X = tf.reshape(tf.range(12, dtype=tf.float32), (3, 4))
Y = tf.constant([[2.0, 1, 4, 3], [1, 2, 3, 4], [4, 3, 2, 1]])

```

**PaddlePaddle:**


## 2.1.3 Механизм broadcasting

Выше мы видели, как выполнять поэлементные операции над тензорами одинаковой формы.
**Даже при разных формах можно выполнять поэлементные операции, используя *механизм broadcasting***.
Он работает так:

1. Один или оба массива расширяются за счёт копирования элементов так, чтобы после преобразования оба тензора имели одинаковую форму;
2. Над полученными массивами выполняется поэлементная операция.

В большинстве случаев broadcasting происходит вдоль осей длины 1, как в следующем примере:

**MXNet:**

```python
a = np.arange(3).reshape(3, 1)
b = np.arange(2).reshape(1, 2)
a, b
```

**PyTorch:**

```python
a = torch.arange(3).reshape((3, 1))
b = torch.arange(2).reshape((1, 2))
a, b
```

**TensorFlow:**

```python
a = tf.reshape(tf.range(3), (3, 1))
b = tf.reshape(tf.range(2), (1, 2))
a, b
```

**PaddlePaddle:**

```python
a = paddle.reshape(paddle.arange(3), (3, 1))
b = paddle.reshape(paddle.arange(2), (1, 2))
a, b
```

Поскольку `a` и `b` — матрицы формы $3\times1$ и $1\times2$, их непосредственное сложение невозможно: формы не совпадают.
Мы *расширяем* (broadcast) обе матрицы до одной большей матрицы $3\times2$: матрица `a` копирует столбец, матрица `b` копирует строки, а затем результаты складываются поэлементно.

**MXNet, PyTorch, TensorFlow, PaddlePaddle:**

```python
a + b
```

## 2.1.4 Индексация и срезы

Как и в любом другом массиве Python, к элементам тензора можно обращаться по индексам.
Как и во всех массивах Python, первый элемент имеет индекс 0, а последний — индекс -1;
для указания диапазона можно задавать границы, при которых включается первый элемент и исключается последний.

Так, **с помощью `[-1]` можно выбрать последний элемент, а с помощью `[1:3]` — второй и третий элементы**:

```python
X[-1], X[1:3]
```

**MXNet, PyTorch:** **Помимо чтения, с помощью индексов можно записывать значения в элементы матрицы.**

**TensorFlow:** Тензоры (`Tensors`) в TensorFlow неизменяемы и не поддерживают присваивание.
Переменные (`Variables`) в TensorFlow — изменяемые контейнеры, в которые можно присваивать значения.
Помните, что в TensorFlow градиенты не распространяются обратно через `Variable`.
Кроме присваивания всей переменной целиком, можно записывать значения и в отдельные элементы `Variable` по индексу.

**MXNet, PyTorch, PaddlePaddle:**

```python
X[1, 2] = 9
X
```

**TensorFlow:**

```python
X_var = tf.Variable(X)
X_var[1, 2].assign(9)
X_var
```

Если нужно **присвоить одно и то же значение нескольким элементам, достаточно проиндексировать все нужные элементы и присвоить им значение.**
Например, `[0:2, :]` обращается к первой и второй строкам, где «:» означает все элементы вдоль оси 1 (столбцы).
Хотя мы говорим об индексации матриц, это работает и для векторов и для тензоров с более чем двумя осями.

**MXNet, PyTorch, PaddlePaddle:**

```python
X[0:2, :] = 12
X
```

**TensorFlow:**

```python
X_var = tf.Variable(X)
X_var[0:2, :].assign(tf.ones(X_var[0:2,:].shape, dtype = tf.float32) * 12)
X_var
```

## 2.1.5 Экономия памяти

**Некоторые операции могут приводить к выделению памяти под новый результат**.
Например, если написать `Y = X + Y`, то `Y` будет указывать не на прежний тензор, а на тензор в новой области памяти.

В примере ниже мы покажем это с помощью функции `id()` из Python, которая возвращает адрес объекта в памяти.
После выполнения `Y = Y + X` видно, что `id(Y)` указывает на другое место.
Это происходит потому, что Python сначала вычисляет `Y + X`, выделяет под результат новую память, и только потом переставляет `Y` на эту новую область.

```python
before = id(Y)
Y = Y + X
id(Y) == before
```

Такое поведение может быть нежелательно по двум причинам:

1. Во-первых, нам не хочется без необходимости постоянно выделять память. В машинном обучении могут быть сотни мегабайт параметров, которые обновляются многократно в секунду. Обычно такие обновления хотелось бы выполнять на месте (in-place);
2. Во-вторых, если не обновлять на месте, на старую область памяти по-прежнему будут ссылаться другие переменные, и часть кода может случайно использовать устаревшие параметры.

**MXNet, PyTorch:** К счастью, **выполнить операцию на месте** очень просто.
Можно присвоить результат операции заранее выделенному массиву с помощью срезов, например `Y[:] = <выражение>`.
Чтобы показать это, сначала создадим новую матрицу `Z` той же формы, что и `Y`, и с помощью `zeros_like` выделим блок из одних нулей.

**TensorFlow:** `Variables` — это изменяемые контейнеры в TensorFlow, которые позволяют хранить параметры модели.
Результат операции можно присвоить `Variable` с помощью `assign`.
Чтобы показать это, создадим `Z` той же формы, что и тензор `Y`, и с помощью `zeros_like` выделим блок из одних нулей.

**MXNet:**

```python
Z = np.zeros_like(Y)
print('id(Z):', id(Z))
Z[:] = X + Y
print('id(Z):', id(Z))
```

**PyTorch:**

```python
Z = torch.zeros_like(Y)
print('id(Z):', id(Z))
Z[:] = X + Y
print('id(Z):', id(Z))
```

**TensorFlow:**

```python
Z = tf.Variable(tf.zeros_like(Y))
print('id(Z):', id(Z))
Z.assign(X + Y)
print('id(Z):', id(Z))
```

**PaddlePaddle:**

```python
Z = paddle.zeros_like(Y)
print('id(Z):', id(Z))
Z = X + Y
print('id(Z):', id(Z))
```

**MXNet, PyTorch:** **Если в дальнейших вычислениях `X` не используется, можно также написать `X[:] = X + Y` или `X += Y`, чтобы уменьшить затраты памяти на операцию.**

**TensorFlow:** Даже если вы храните состояние в `Variable`, может понадобиться избегать лишнего выделения памяти под тензоры, которые не являются параметрами модели, чтобы дополнительно снизить расход памяти.
Поскольку тензоры TensorFlow неизменяемы, а градиенты не проходят через `Variable`, TensorFlow не предоставляет явного способа выполнить отдельную операцию на месте.
Однако TensorFlow предоставляет декоратор `tf.function`, который заключает вычисления в граф TensorFlow; перед запуском граф компилируется и оптимизируется.
Это позволяет TensorFlow удалять неиспользуемые значения и повторно использовать ранее выделенную память для значений, которые уже не нужны.
Так расход памяти на вычисления в TensorFlow сводится к минимуму.

**MXNet, PyTorch, PaddlePaddle:**

```python
before = id(X)
X += Y
id(X) == before
```

**TensorFlow:**

```python
@tf.function
def computation(X, Y):
    Z = tf.zeros_like(Y)  # Это неиспользуемое значение будет удалено
    A = X + Y  # Когда оно больше не нужно, память будет переиспользована
    B = A + Y
    C = B + Y
    return C + Y

computation(X, Y)
```

## 2.1.6 Преобразование в другие объекты Python

**MXNet, TensorFlow:** **Преобразовать тензор фреймворка глубокого обучения в NumPy-тензор (`ndarray`) несложно, и обратное преобразование тоже.**
Результат при этом не разделяет память с исходным тензором.
Эта небольшая неприятность на самом деле очень важна: при вычислениях на CPU или GPU, если пакет NumPy в Python тоже захочет использовать тот же блок памяти для других операций, не хочется останавливать вычисления и ждать его.

**PyTorch:** **Преобразовать тензор фреймворка в NumPy-тензор (`ndarray`)** так же просто, и обратно.
Тензоры torch и массивы numpy разделяют одну и ту же область памяти, поэтому изменение одного из них (в том числе операцией на месте) меняет и другой.

**MXNet:**

```python
A = X.asnumpy()
B = np.array(A)
type(A), type(B)
```

**PyTorch:**

```python
A = X.numpy()
B = torch.tensor(A)
type(A), type(B)
```

**TensorFlow:**

```python
A = X.numpy()
B = tf.constant(A)
type(A), type(B)
```

**PaddlePaddle:**

```python
A = X.numpy()
B = paddle.to_tensor(A)
type(A), type(B)
```

Чтобы **преобразовать тензор размера 1 в скаляр Python**, можно вызвать функцию `item` или встроенные функции Python.

**MXNet:**

```python
a = np.array([3.5])
a, a.item(), float(a), int(a)
```

**PyTorch:**

```python
a = torch.tensor([3.5])
a, a.item(), float(a), int(a)
```

**TensorFlow:**

```python
a = tf.constant([3.5]).numpy()
a, a.item(), float(a), int(a)
```

**PaddlePaddle:**

```python
a = paddle.to_tensor([3.5])
a, a.item(), float(a), int(a)
```
