## 2.7.1 Поиск всех функций и классов модуля

Чтобы узнать, какие функции и классы можно вызывать в модуле, используют функцию `dir`.
Например, мы можем **получить список всех атрибутов модуля генерации случайных чисел:**

**MXNet:**

```python
from mxnet import np
print(dir(np.random))
```

**PyTorch:**

```python
import torch
print(dir(torch.distributions))
```

**TensorFlow:**

```python
import tensorflow as tf
print(dir(tf.random))
```

**PaddlePaddle:**

```python
import warnings
warnings.filterwarnings(action='ignore')
import paddle
print(dir(paddle.distribution))
```

Обычно можно не обращать внимания на функции, имена которых начинаются и заканчиваются на «`__`» (двойное подчёркивание): это специальные объекты Python.
Также можно пропустить функции, имена которых начинаются с одиночного «`_`»: обычно это внутренние функции.
По оставшимся именам функций и атрибутов можно предположить, что этот модуль предоставляет различные методы генерации случайных чисел, в том числе выборку из равномерного (`uniform`), нормального (`normal`) и мультиномиального (`multinomial`) распределений.

## 2.7.2 Поиск применения конкретных функций и классов

Более подробное описание того, как использовать заданную функцию или класс, можно получить с помощью функции `help`.
Например, **посмотрим, как использовать функцию `ones` для создания тензоров.**

**MXNet:**

```python
help(np.ones)
```

**PyTorch:**

```python
help(torch.ones)
```

**TensorFlow:**

```python
help(tf.ones)
```

**PaddlePaddle:**

```python
help(paddle.ones)
```

Из документации видно, что функция `ones` создаёт новый тензор заданной формы и задаёт значения всех его элементов равными 1.
Далее **проверим это описание на небольшом примере**:

**MXNet:**

```python
np.ones(4)
```

**PyTorch:**

```python
torch.ones(4)
```

**TensorFlow:**

```python
tf.ones(4)
```

**PaddlePaddle:**

```python
paddle.ones([4], dtype='float32')
```

В Jupyter Notebook можно использовать символ `?`, чтобы открыть документацию в другом окне браузера.
Например, команда `list?` выведет почти то же, что и `help(list)`, но в новом окне браузера.
Кроме того, если написать два знака вопроса, как в `list??`, будет показан код Python, реализующий эту функцию.
